# 얼쑤 부스 설문

부스 체험을 마친 분이 아이패드에서 직접 작성하고 가는 설문. `index.html` 한 장이 전부다.

**설문 주소** <https://insightrookie.github.io/survey/>

> 여기가 **원본**이다. 고칠 일이 있으면 이 저장소의 `index.html` 을 고친다.
> (예전에 쓰던 `912eun/survey` 는 더 이상 쓰지 않는다.)

---

## 응답은 시트로, 음성은 아이패드에

```
[아이패드]  ──객관식 응답──▶  Apps Script  ──▶  구글 시트
     └── 음성 ──▶  아이패드 안 (IndexedDB) — 밖으로 나가지 않는다
```

목소리는 사람을 가려낼 수 있는 정보다. 구글 드라이브로 보내면 **제3자 제공과 국외 이전**이
되어 처리방침과 동의서에 Google 을 적고 따로 동의를 받아야 한다. 응답만 보내고 음성은 기기에
두면 그 일이 없어진다.

**대신 이어 볼 수 있다.** 시트의 `submission_id` 와 **같은 이름**으로 파일이 만들어진다.

```
시트 한 줄  :  submission_id = m2k9x7q3a1b2  …  voice = "음성 42초 · 기기 보관"
기기 안 파일 :  m2k9x7q3a1b2_voice.webm
```

음성이 있는 줄은 그 칸에 길이가 적히므로, **시트만 봐도** 어느 응답에 음성이 있는지 보인다.

---

## 음성 꺼내기

설문 화면 **왼쪽 위 모서리를 다섯 번** 톡톡 치면 운영자 패널이 열린다.

| | |
|---|---|
| 음성 전체 내려받기 (.zip) | `음성/` 폴더 + `음성목록.csv`(submission_id ↔ 파일 이름) |
| 한 건씩 | 목록에서 `받기` |

하루가 끝나면 받아서 **암호화 외장하드**로 옮기고, 아이패드 쪽은 Safari 설정에서 사이트
데이터를 지운다. 보관 기준은 체험 영상과 같다 — **1개월 · 접근 5인**.

---

## 아이패드 설정 — 빠뜨리면 현장에서 고생한다

| 할 일 | 어디서 |
|---|---|
| **마이크 허용 고정** | 주소창 **가가(aA) → 웹사이트 설정 → 마이크 → 허용** |
| **자동 잠금 끄기** | 설정 → 디스플레이 및 밝기 → 자동 잠금 → **안 함** |
| **가이드 접근** | 설정 → 손쉬운 사용 → 가이드 접근 켜기 · 쓸 때 전원 세 번 |
| **홈 화면에 추가** | 공유 → 홈 화면에 추가 (주소창 없이 전체 화면) |
| 충전기 연결 | — |

마이크 허용 고정이 제일 중요하다. 안 해 두면 **녹음할 때마다 허용 창**이 떠서 흐름이 끊긴다.

## 문항 고치기

`index.html` 위쪽 **"✏️ 여기만 고치면 돼요"** 부분만 보면 된다.

| type | 쓰임 | 함께 적는 것 |
|---|---|---|
| `single` | 하나만 고르기 | `options` |
| `multi` | 여러 개 고르기 | `options` |
| `stars` | **별점(0.5 단위)** | `max`(기본 5) |
| `range` | **밀어서 고르기** | `min` `max` `step` `start` `ticks` `format` |
| `scale` | 숫자 척도 | `min` `max` `labels` |
| `text` | 자유 서술 | `placeholder` |
| `record` | 음성 녹음 | — |

`showIf` 로 앞 응답에 따라 보여 줄지 정한다. 녹음 문항 앞에는 **반드시 동의 문항**을 두고,
동의한 분에게만 녹음 문항이 보이게 한다.

```js
{ id: 'price', type: 'range', required: true,
  title: '이 게임의 가격은 얼마가 적당할까요?',
  min: 0, max: 20000, step: 1000, start: 10000,
  ticks: ['무료', '1만원', '2만원'],
  format: v => v === 0 ? '무료라면 할래요' : v.toLocaleString('ko-KR') + '원' },
```

`id` 는 영문·숫자·밑줄만 쓴다 — 시트의 열 제목이 된다.

## 고친 뒤

이 저장소에서 `index.html` 을 **Commit** 하면 1~2분 뒤 같은 주소에 반영된다.
Apps Script 코드를 고쳤다면 **배포 → 배포 관리 → ✏️ → 새 버전 → 배포** 까지 해야 한다
(「새 배포」를 누르면 URL 이 바뀐다).

---

## ⚠️ 부스가 끝나면

- [ ] 음성 내려받아 암호화 외장하드로 옮기고, 아이패드 사이트 데이터 지우기
- [ ] **이 저장소를 Private 으로 바꾸거나 지우기**
- [ ] **Apps Script 배포 중지**

저장소가 Public 이라 `index.html` 안의 웹 앱 URL 을 누구나 볼 수 있다. 그 URL 로는 응답을
**추가**하는 것만 되고 시트를 읽을 수는 없지만, 표본이 50~200 건이라 장난 응답 몇 건이
비율을 크게 흔든다.
